| [0001](0001-client-and-server-stack.md) | accepted | stack | Client and server stack | In the context of a notes app with iOS, web and desktop clients and a self-hosted server, facing the cost of several client codebases and parsers, we decided on React Native with React Native Web, Electron and a Node and TypeScript server in a pnpm monorepo and rejected separate native clients and Flutter, to achieve one client codebase for iOS and web and one parser for client and server, accepting that the editor component is still an open risk. | – |

| [0004](0004-scaffold-toolchain.md) | accepted | stack | Scaffold toolchain and workspace layout | In the context of scaffolding the stack of ADR 0001, facing build tooling that is costly to change once code depends on it, we decided on one Expo app for iOS and the web, an Electron wrapper of its web export, a Fastify and TypeBox server, and Biome, strict TypeScript, Vitest and Jest in a pnpm workspace and rejected a bare React Native app with a separate Vite web app, Express or Hono, and ESLint with Prettier, to achieve one client codebase and one API contract, accepting that Expo SDK upgrades pace React Native. | – |
